# 01 · 背景与目标

> [返回首页](../README.md)

## 痛点

试卷在交付（考试、出版、题库入库）之前需要人工审校，传统做法的问题：

- **量大**：一份卷子几十到上百题，一个批次几十份卷子，人工逐题逐字看不过来。
- **口径不统一**：不同审校员对「这算不算错」「算多严重」判断不一致。
- **易漏**：错别字、标点、选项缺项还好查；**图文是否对得上**（图里标的值和题干说的不一样）、**和历史题是否撞车**，靠人眼几乎查不全。
- **多语言**：中/日/德/法试卷各有各的拼写、语法、标点规范，审校员未必都精通。

## 目标

把审校做成一个**可路由、可复核、可量化**的流水线平台：

1. **自动拆题**：把整份文档拆成结构化的逐题清单（大题/小题/层级、题干、选项、答案、参考材料）。
2. **按题路由**：每道题先判断「需要查哪些类型的问题」，避免对不适用的题做无效检测。
3. **多类检测**：错别字、语义、选项、标点、题型、信息缺失、题目无解、答案泄露、**图文一致性**等，多语言覆盖。
4. **去重聚合**：把多任务、同位置、同根因的重复报错合并成一份干净清单。
5. **查重**：卷内、同批同学科卷间、与历史卷之间三类查重。
6. **评测**：用带标注的数据集量化检测能力（precision/recall/F1/F2）。
7. **复核与沉淀**：人工对每条问题确认/驳回/备注，并可把典型判断沉淀进案例库（动态 Few-shot）。
8. **产出报告**：Word 审校报告、Excel 问题明细、检测过程明细、整批 ZIP。

## 目标用户

- **教研 / 审核人员**：把大量试卷先自动过一遍，减少人工初筛。
- **出版 / 题库运营**：批量质检、历史去重、版本回归。
- **模型 / 数据团队**：用评测主线量化「换了模型 / 加了案例库」前后的检测效果。

## 为什么是「难点在图文」

文本类错误（错别字、标点）相对成熟；真正难、又最有价值的是**图文一致性**：一道含图题，题干说「图中夹角为 30°」而图里画的是 45°，或者干脆配错了别的题的图。多模态模型在这类细粒度图文对账上**容易「看图说话流畅、却漏掉关键锚点」**。本项目为此设计了一条四段式多模态链路（见 [07](07-图片审校深挖.md)），并把这条链路的检测能力沉淀成了一个独立的图文一致性基准 [EduFig-IC](https://github.com/CODE-BULIAO/edufig-ic)。

## 最终产物

| 产物 | 用途 |
|------|------|
| 逐题问题清单 | 审核人员逐条复核（题号、类型、严重度、说明、修改建议、原文锚点） |
| Word 审校报告 | 给教研/审核/外部协作方阅读、流转 |
| Excel 问题明细 | 筛选、统计、二次处理 |
| 检测过程明细 Excel | 查看每次检测的输入/输出/耗时/是否命中案例库 |
| Excel 评估报告 | precision/recall/F1/F2/FPR 等效果指标 |
| 批次 ZIP | 一次性打包下载整批结果 |
